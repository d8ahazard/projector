# Launch checklist and press kit

## Core message

Projector turns commodity Android TV sticks into synchronized, calibrated projection players. It focuses on long-running multi-surface shows, not one-off video playback.

## Proof points

- arbitrary surface count in the scheduler
- local per-player caching and absolute-time playback
- one-click folder/ZIP package import and multi-pack shuffle
- calibration-aware portrait/landscape selection
- movement-aware character handoffs
- reversible dedicated-stick setup without root
- local AI generation with explicit approval gates

## Assets already prepared

- phone Live UI
- package-import UI
- calibration UI
- Programs UI
- Creature Studio UI
- generated two-window crossing storyboard

## Still needed before launch

- repository URL substituted for placeholders
- one real exterior/night photo
- one 15–30 second real two-projector demo video
- projector models and measured output modes
- first GitHub release URL and checksum
- final project owner/byline

## Suggested release tagline

One house. Any number of projectors. Characters that know where the next window is.
